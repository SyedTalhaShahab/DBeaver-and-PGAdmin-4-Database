# DBeaver-and-PGAdmin-4-Database
1. Install "DBeaver" and "Postgresql" by checking "PGAdmin 4" and "Stack" Option.
2. Change directory in terminal to "frontEnd" and "npm install" so folder name "node_modules" gets created.
3. Change directory in terminal to "backEnd" and "python3 -m venv myenv" so folder name "venv" for virtual environment gets created.
8. Change directory in terminal to "frontEnd" and run "node app.js"
6. Change directory in terminal to "backEnd" and run "python back.py"
