# DBeaver-and-PGAdmin-4-Database
1. Install "DBeaver" and "Postgresql" by checking "PGAdmin 4" and "Stack" Option.
2. Go to terminal and change directory to "frontEnd" and "npm install" so folder name "node_modules" gets created.
3. Go to terminal and change directory to "backEnd" and "python3 -m venv myenv" so folder name "venv" for virtual environment gets created.
8. Go to terminal and change directory to "frontEnd" and run "node app.js"
6. Go to terminal and change directory to "backEnd" and run "python back.py"
